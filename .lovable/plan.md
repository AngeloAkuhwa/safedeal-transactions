# Agent Performance — what is still left

Sections 1 and 2 of the earlier plan are done. Confirmed in the code:

- Rankings: `ScoreBreakdownDialog.tsx` and `RankingsFilters.tsx` exist, the service carries `min_completed`, `performance_level`, `hide_insufficient`, and score components/penalties/exclusions.
- Agent Details drawer: six tabs are in place (Overview, Current Workload, Performance, SLA, Case History, Activity).

Four areas from your newer message are **not** complete.

## 1. Date ranges are incomplete

The range selector currently offers This Week, Last 7 Days, Last 30 Days, This Month (plus All Time scope). The type allows `custom` but there is no custom UI.

Add: Today, Previous Month, Current Quarter and a working Custom Range picker (from/to), all passed through to the backend range resolver and reflected in the range label used by charts, comparisons and exports.

## 2. Missing page filter: Case stage

Team, role, agent search, availability, workload status, case priority, case status, case SLA, SLA state, performance level and min completed all exist. **Case stage** does not exist on the filter bar, in the filter type, or in the backend case matcher.

Add `case_stage` end to end (More Filters control, service type + default, backend `caseMatch`), so it narrows summary cards, Workload, Performance, SLA Compliance, Rankings and the drawers like every other case filter.

## 3. URL preservation for the new filters

The page already mirrors tab and SLA sub-filters to the query string. Extend `filtersFromParams` / the writer so date preset, custom from/to, case stage, performance level, min completed and hide-insufficient round-trip, so a filtered screen can be shared.

## 4. Export Report is one generic CSV

Today every tab exports the same agent-row columns, and the file has no context header.

Fix:
- Report type per tab — Workload, Performance, SLA Compliance, Rankings, and Filtered Agent (single agent when the drawer is open) — each with columns matching that view.
- Prepend a metadata block: report type, selected date range, applied filters, generated date, generated by.
- Keep the existing `agent_performance.export` permission, the mandatory reason, PII masking and the audit-log write. No new permission.

## 5. Final review pass

Run through the review checklist against the built screen and fix what fails:

- Scope: confirm nothing added market agents, vendor onboarding, referrals, commissions, a separate portal, or new roles/permissions.
- Functionality: every tab, card, sort, page control, View Detail, View Cases, Review SLA, Rebalance deep link and Export path exercised once with real data.
- Data accuracy: resolved uses resolution date, open excludes resolved/closed/cancelled, overdue requires a real SLA due date, no duplicate assignment counting, previous-period comparison uses an equal-length window.
- Security: route guard plus API-layer permission checks on the hidden actions.
- UX: responsive tables without uncontrolled horizontal scroll, keyboard focus in drawers/dialogs, accessible labels on icon buttons, non-colour status cues, Retry on error states.
- Clear any TypeScript, console, routing or data-access errors surfaced during the pass.
